# KIKO 2D 骨骼动画内核

此目录实现了真实的 2D 网格蒙皮运行时：骨骼层级、世界矩阵、顶点权重、三角网格纹理变形和可混合动作层。它不是 CSS transform 动画。

## 资产状态（重要）

运行时要求一份与 KIKO 原图严格对应的 rig manifest：原图尺寸、三角网格顶点/索引、每个顶点的骨骼权重，以及角色骨骼树。当前仓库中的 `kiko.png` 是二进制 PNG；自动化 GitHub 文本读取接口无法读取其像素，因此这里没有臆造顶点、分割轮廓或遮挡补绘，也没有把其他熊猫图替换成 KIKO。

仅凭一张扁平图，角色背后和关节遮挡处的像素本来就不存在。正式制作需要以原图为底稿补绘独立肢体层，再为其生成网格和权重。未完成这一步之前，不应宣称完整的跳跃、拍肚皮、打滚骨骼动作已经交付。

## 运行时 API

- `new Skeleton(definition)` 建立骨骼层级。
- `new Skinning(mesh)` 建立三角网格并按顶点权重变形。
- `MotionMixer.play(name, clip, options)` 混合动作层。
- `AnimationEngine(canvas, image, rig)` 将蒙皮结果绘制到透明 canvas。

manifest 和源图尺寸必须由原图分析/角色拆分流程生成。不要将整张贴图旋转作为替代。
